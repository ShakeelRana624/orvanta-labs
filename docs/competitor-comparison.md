# Orvanta Labs: competitor website comparison and implemented improvements

Reviewed 15 November 2026. This is a comparison of publicly readable content and buyer journeys with Orvanta's current source. It does not measure competitor conversion rates, revenue, technical quality, or live performance. Competitor customer/result claims are their published claims, not independently verified facts.

## Gaps and changes

| Area | Orvanta before | Change implemented |
| --- | --- | --- |
| Positioning | General AI slogan; target buyer unclear | Explicit computer vision/applied AI headline and software-team, agency and operations-team context. |
| First-screen proof | Work was lower on the page | Factual links to 10 projects, the founder and defined-scope engagements near the hero. |
| Service discovery | CV combined with ML in the main card list | Four distinct service entries; CV is directly visible. |
| Evidence connections | Portfolio and service pages were largely separate | Relevant project links on each service; project pages connect back to scope and evaluation. |
| Buying clarity | Generic pilot language | A separate engagements page covers discovery, a defined pilot, integration, deliverables, scope changes and running costs. |
| Service depth | Capabilities and prerequisites only | Proposed outputs and service-specific evaluation guidance, clearly subject to the written scope. |
| Buyer questions | Dedicated FAQs were missing from current multi-page site | Native accessible FAQ sections address data, cost factors, timelines, evaluation, ownership and agency partnerships. |
| Enquiry friction | User had to reselect a service after following a service CTA | Allowlisted query parameters preselect the service; direct email remains an alternative. |
| Search/share metadata | Identical page descriptions; no canonical/sitemap | Unique descriptions, canonicals, Open Graph text, favicon, sitemap and robots file. These do not make a private site public or guarantee indexing. |
| Image delivery | Cards referenced 4K files for every device | 960/1920/3840 srcsets preserve 4K originals and let browsers choose a lighter card image. |
| Navigation | No route explaining engagement choices | Engagements added to shared navigation/footer; menu breakpoint adjusted for the extra item. |

## Genuine proof still needed

A polished website cannot create delivered client outcomes. Orvanta currently has personal, academic and open-source engineering evidence. We retained those distinctions and existing team credit. No customer logos, testimonials, revenue impact, accuracy guarantees, team headcount or fixed turnaround promises were invented.

The next useful proof would be a real paid pilot, a permissioned client testimonial, and a documented before/after evaluation with its dataset and limitations. These are business milestones, not missing decorative website sections.

## Launch blockers retained honestly

- Site remains owner-private. Sharing access was not changed without a request.
- FormSubmit recipient activation and an actual delivered-email test remain unverified. The earlier setup request was blocked by the provider's browser-signature policy. The direct email route remains available.
- Exact inline fraud screenshot and three large uploaded videos still need accessible file inputs; this revision does not claim they were imported.
- Visual browser/device QA remains limited by the managed preview relay failure. No measured Core Web Vitals score or conversion improvement is claimed.

## Validation

Checked page/asset/anchor/srcset references, unique IDs and metadata, service-to-project links, contextual service selection and invalid-parameter handling, existing email success/error/timeout-adjacent handling, responsive CSS breakpoints, and preserved security/privacy behavior. Image-size figures in research/image-size-comparison.json compare files, not actual load time.

Brand infrastructure remains a business follow-up: a custom domain and matching email address would make the public identity more consistent. No domain purchase, mailbox setup, or availability claim was made.

Image file comparison: the ten 4K thumbnail files total 1,909,294 bytes; the ten 960px derivatives total 274,256 bytes. Browsers select candidates using srcset; this is not a measured speedup.
