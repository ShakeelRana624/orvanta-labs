# Rehvector AI

A buildless, multi-page agency website. Serve the `dist` directory. No backend or dependencies are needed.

19 HTML pages: home, services, four service details, categorized work, nine project details, about, contact, privacy.

Project selection was approved by Shakeel Ur Rehman, including the phishing classifier. Content comes from the public ShakeelRana624 GitHub repositories and the portfolio repository. LinkedIn content could not be fetched; the owner requested social post links be omitted. Restaurant and phishing summaries are portfolio descriptions, labelled accordingly. Resume Analyzer follows the reviewed Flask repository instead of unverified subscription claims. Portfolio/README metrics are not represented as independent client results.

Assets: founder portrait from portfolio/master/shakeel.png; SKYWATCH dashboard recording from smart-IoV-based-coordination-system-for-urban-emergency-monitoring-and_response; drone recording/sample frame from anti-drone-telemetry-defense-system/output_videos; pose images/animation from RealTime-Pose-Estimation-Engine; churn screenshot from Customer-Churn-Prediction. Videos are web-encoded, without audio. Diagrams for projects without media are explicitly illustrative.

Contact form constructs a WhatsApp draft. Nothing is submitted to an application database. No outreach is sent by this site.

Checks completed: JS syntax, all 19 pages' local links/assets and unique IDs; category counts, search, empty results, URL query restoration, menu state; video codec/duration checks. Visual browser QA was blocked by the managed preview relay readiness timeout. Audience remains owner-private.
